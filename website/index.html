Focused local tools

Small utilities. One useful workbench.

Cmdry is a self-hosted web workbench for formatting text, converting data, working with images, generating values, and inspecting your own server.

Open the demo → View on GitHub
What it does

Transform

Format JSON, convert CSV, clean up lists, encode text, and handle everyday data chores.

Create

Generate hashes, GUIDs, passwords, QR codes, timestamps, and other useful values.

Run locally

Keep tools close to your own environment. Plugins are separate executables with structured responses.

Quick start

Run Cmdry yourself

Clone the repository, build the core and bundled plugins, then run it locally.

git clone https://github.com/sottey/cmdry.git
cd cmdry
./scripts/build.sh
./scripts/run.sh

Cmdry listens on http://127.0.0.1:8080 by default. See the README for plugins, Docker, and public-demo setup.
